# Defenses

`01_adversarial_training` implements PGD-AT (Madry et al., 2018) as a mixed-batch objective: for every batch, a 5-step PGD adversarial example is generated and the model trains on the average of clean and adversarial loss. An initial attempt at pure adversarial training (no clean-loss term) collapsed accuracy to 19.8%, documented directly in the notebook, and was fixed by mixing the two losses. At the reduced scale this repo runs at (1500 fine-tuning clips, 5 epochs), the result is honestly negative: clean accuracy drops (56.5% to 48.5%), FGSM's attack success rate actually rises (68.1% to 82.0%), and PGD stays saturated at 100% in both models. The same finding as the vision repo's GTSRB adversarial training: real adversarial robustness needs far more compute than a CPU-scale experiment can provide, and a modest run mostly demonstrates that the pipeline works end to end, not that it produces a robust model.

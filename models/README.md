# Models

`01_train_keyword_spotter` trains KeywordCNN from scratch, three Conv2d+BatchNorm blocks over 64-band log-mel spectrograms of one-second, 16kHz clips, on a reduced subset of Google Speech Commands (400/60/60 clips per class for train/val/test across 10 commands). Unlike the vision and NLP repos, which attack a large pretrained model, this one is trained from nothing specifically so the full attack-defense loop, including retraining in `defenses/`, stays tractable on a CPU. Test accuracy lands at 58.2% (chance is 10%): a real, well-above-chance signal, but a deliberately modest one, with noisy epoch-to-epoch validation accuracy typical of a small dataset and no early stopping. This notebook also defines `waveform_to_spectrogram`, reused as-is by every other notebook in the repo that needs to look inside the model.
